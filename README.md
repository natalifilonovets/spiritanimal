# Which Cosmic Animal Are You?

Англоязычный мини-тест из 12 вопросов для практики чтения и устной речи на уровне A1–A2.

## Локальный запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются. Вопросы, логика и рисунки доступны офлайн. Если Google Fonts недоступны, браузер использует системные шрифты.

## Файлы

- `index.html` — стартовый экран и подключение ресурсов.
- `styles.css` — адаптивная вёрстка, звёздный фон и анимации.
- `data.js` — вопросы, варианты и тексты шести результатов.
- `script.js` — перемешивание, навигация, подсчёт и смена экранов.
- `assets/cover.png` и `assets/stars.svg` — обложка и фоновые созвездия.
- `assets/animals/` — шесть локальных портретов в PNG.
- `.nojekyll` — отключает обработку файлов через Jekyll на GitHub Pages.

Каждый ответ добавляет один балл своему животному. При равенстве побеждает животное из группы лидеров, которое встречается в ответах ближе к концу теста. Изменение ответа заменяет прежний выбор. Варианты перемешиваются один раз при запуске игры и сохраняют порядок при возврате.

## GitHub Pages

1. Загрузите содержимое папки, включая `.nojekyll` и `assets/`, в корень ветки `main` репозитория.
2. Откройте **Settings → Pages**, в поле **Source** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. После деплоя откройте URL из **Settings → Pages**. Для сайта проекта он обычно имеет вид `https://<owner>.github.io/<repository>/`.

[Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Иллюстрации

Шесть портретов и обложка сгенерированы встроенным OpenAI ImageGen специально для этого проекта. Фоновые созвездия — оригинальный SVG. Сторонние изображения не использованы.

Общий промпт для серии — отдельная квадратная иллюстрация в стиле кинематографической сказочной живописи, естественная анатомия, детальные текстуры, тёмно-синие края, звёздная пыль и направленный цветной свет, без текста и рамок.

- Лиса — рыжая шерсть, янтарные глаза, пышный хвост, золотые созвездия.
- Волк — серебристо-голубая шерсть, полная луна и лунная пыль.
- Сова — раскрытые узорчатые крылья, астрономические кольца, сиреневый и золотой свет.
- Дельфин — прыжок сквозь кольцо воды, бирюзовые брызги и розово-синяя туманность.
- Кот — пушистая шерсть, светящиеся глаза, розово-лиловая туманность и звёздное окно.
- Олень — светящиеся ветвистые рога, космический лес, бирюзовые и золотые блики.
- Обложка — фиолетовая туманность, золотая круговая звёздная карта и едва заметные созвездия в форме животных.
